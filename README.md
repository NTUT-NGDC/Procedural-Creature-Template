# Procedural Creature Template

北科遊戲研究社「每週交流會」**程序化動畫**主題課的模板專案。

在遊戲內的「生物工坊」用滑桿、按鈕組出一隻自己的生物（蛇、蜈蚣、章魚、蜘蛛……），放進「生態缸」小遊戲裡玩，匯出網頁版，上傳到 itch.io 和大家互相試玩，**整堂課都不用寫程式。**

生物的身體、腳、觸手都不是一格一格畫的動畫，而是每一幀用幾行數學算出來的：身體是**鏈條跟隨**、觸手是 **FABRIK**、腳是 **Two-Bone IK＋換腳**。

## 📖 學員手冊

**👉 [交流會學員手冊（Notion）](https://app.notion.com/p/2949b83c066846079f3a609f8808d513?source=copy_link)**

操作步驟、教學步驟的每一步、匯出上傳、常見問題都在手冊裡，上課時打開程序化動畫那一頁照著做就好。

## 需要準備

| 項目 | 版本 | 說明 |
| --- | --- | --- |
| Godot | **4.7.2**（標準版，非 .NET） | [下載頁面](https://godotengine.org/download/archive/4.7.2-stable/)。請用這個版本，其他版本可能打不開專案 |
| Godot 匯出模板 | 4.7.2 | 匯出網頁版需要，同一個下載頁面有，或在 Godot 裡「編輯器 → 管理匯出模板」下載 |

不用裝任何外掛。

> 上課時教室網路慢，Godot 和匯出模板會放在社課的 USB 裡。

## 取得專案

按上方綠色的 **Code → Download ZIP**，下載後解壓縮。（會用 git 的人也可以 fork 再 clone，不過這是上課用的工具，之後幾乎不會更新，直接下載就好。）

接著打開 Godot，在專案管理員按「匯入（Import）」，選資料夾裡的 `project.godot`，再按「匯入並編輯」。第一次打開會花一點時間匯入，等進度條跑完再開始。

## 快速開始

| 想做什麼 | 怎麼做 |
| --- | --- |
| 玩玩看生態缸 | 按 `F5`，從標題畫面按「開始遊戲」 |
| 沒靈感，抽一組題目 | 打開 `lesson/card_draw/card_draw.tscn`，按 `F6` |
| 組自己的生物（跟著教學步驟做） | 打開 `lesson/workshop/workshop.tscn`，按 `F6` |

## 生態缸怎麼玩

- 標題畫面按「＜」「＞」換生物：TitleScreen 檢查器設定的「Player Design」排第一個，也可以換成 `my_creature/` 裡的或範例生物。Player Design 還是範例（例如預設的蛇）的話，一打開會先選 `my_creature/` 裡的第一隻（不想讓玩家換：關掉檢查器的「Allow Choose」）
- 你的生物一直往前衝，**滑鼠決定方向**
- **用頭的前方撞到別人（頭或身體都算，不管誰大）就死掉**，散成一串飼料；頭的側面、後面擦到不算。想辦法讓別人撞上你的身體
- 吃飼料升級，照「長大方式」變長、變粗、長出腳
- **按住任何鍵或滑鼠加速**，會消耗飼料，用完會掉級
- `Esc` 暫停
- 用手機玩網頁版：左半邊推搖桿轉向、按住右下角「加速」、右半邊點一下放飼料（iPhone 還沒測過）

## 專案結構

| 資料夾 | 內容 | 要不要動 |
| --- | --- | --- |
| `my_creature/` | **你自己的生物**：一隻一個資料夾（設計檔 `design.tres`＋你畫的圖） | ✅ 工坊會幫你存到這裡 |
| `example/` | 範例生物（蛇、蜈蚣、章魚、蜘蛛、水母、龍……） | 👀 參考用，不要改 |
| `game/` | 生態缸、標題畫面、暫停選單、生物的零件 | ⚙️ 只改標題畫面 |
| `lesson/` | 抽卡、生物工坊 | ▶️ 打開來用就好 |
| `_system/` | 字型、測試用的東西 | 不用管 |

## ⚠️ 一定要記得

- **工坊裡改完一定要按「存檔」。** 工坊是遊戲，關掉視窗之前沒存的都會不見
- **資料夾名稱只能用英文字母、數字、底線**（例如 `my_dragon`），中文和空白在網頁版會出問題
- **搬移、改名檔案一律在 Godot 的「檔案系統」面板裡做**，不要用檔案總管
